A program that writes one line to `/output/entry.txt` — a deadpan weather forecast for the invented city of Qorvath — for [Deadpan Forecasts for Cities That Do Not Exist](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c) on make.fun. A dry meteorologist judge reads the forecasts two at a time and keeps the one that is funnier and more vivid while still reading like a real broadcast line.

## The line

> In Qorvath, expect light rain of small keys at 14:00, clearing by dusk; residents are advised to check their pockets and carry one umbrella, just in case.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (within the 1–160 gate) and nothing else.

## Layout

- `main.py` — the entry program: writes the Qorvath forecast to `entry.txt`.
